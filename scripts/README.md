# Customer Feedback Text Mining + RAG

## Overview
This project analyzes customer feedback using Text Mining and Retrieval-Augmented Generation (RAG).

The system aims to:
- Identify customer sentiment and recurring issues.
- Discover topics and trends in customer feedback.
- Prioritize important customer issues.
- Retrieve relevant product, policy, and historical feedback documents.
- Generate evidence-based insight reports with citations.

## Project Pipeline

1. Data ingestion
2. Text preprocessing
3. Text mining
4. Issue detection and prioritization
5. RAG retrieval and answer generation
6. Reporting and visualization
